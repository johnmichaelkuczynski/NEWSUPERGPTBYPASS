HOW TO ADD WRITING SAMPLES
==========================
Drop any .txt file into this folder. The filename determines what shows in the app.

SINGLE FILE PER AUTHOR:
  Eudora_Welty.txt             -> Author: "Eudora Welty"

MULTIPLE FILES BY THE SAME AUTHOR (use -- as separator):
  Eudora_Welty--The_Wide_Net.txt       -> Author: "Eudora Welty" / Title: "The Wide Net"
  Eudora_Welty--A_Worn_Path.txt        -> Author: "Eudora Welty" / Title: "A Worn Path"
  Ernest_Hemingway--The_Snows.txt      -> Author: "Ernest Hemingway" / Title: "The Snows"
  Ernest_Hemingway--Hills_Like.txt     -> Author: "Ernest Hemingway" / Title: "Hills Like"

RULES:
  - Use underscores for spaces within a name or title
  - Use -- (double dash) to separate author from title
  - No other changes needed — the app picks up files immediately
