HOW TO ADD WRITING SAMPLES
==========================
Drop any .txt file into this folder.
Name it whatever you want — the filename is what shows in the app.

EXAMPLES:
  Freud.txt         -> "Freud"
  Freud 2.txt       -> "Freud 2"
  Welty.txt         -> "Welty"
  Welty 2.txt       -> "Welty 2"
  Hemingway.txt     -> "Hemingway"

That's it. No special format required.
