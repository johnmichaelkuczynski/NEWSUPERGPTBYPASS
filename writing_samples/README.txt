HOW TO ADD WRITING SAMPLES
==========================
Drop any .txt file into this folder.
The filename becomes the author name shown in the app.

Examples:
  Eudora_Welty.txt       -> "Eudora Welty"
  Ernest_Hemingway.txt   -> "Ernest Hemingway"
  Virginia_Woolf.txt     -> "Virginia Woolf"

The app picks them up automatically — no other changes needed.
